# Gboard Pro v1.0.5 (Beta)

### Changelog Highlights:
- Custom Clipboard History Retention: Added dedicated custom retention settings with presets (1h, 6h, 12h, 24h, 48h, 72h, 168h, 720h, 8760h) and arbitrary hours input directly under "Keep clipboard history for".
- Enhanced Appearance Previews: App launcher icons now display full high-resolution visual previews for all icon variants directly in Settings.
- Material 3 Expressive UI Swatches & Real-time Theming: Gboard UI section now features dynamic multi-tone preview swatches (Rainbow, Botanical, Ocean) that instantly apply expressive Material 3 vibes across the UI.
- AMOLED Pure Black Optimization: Board UI section streamlined to strictly focus on AMOLED Pure Black mode, applying true #000000 pitch-black styling to the keyboard window and background.
- Modernized About Screen: Redesigned hero card featuring the official app icon, version badge (v1.0.5 Beta), project information, and direct community links to developer GitHub and Telegram.
- Universal Smooth Motion Transitions: Fragment navigation across all settings sections (Languages, Preferences, Voice typing, Clipboard, Dictionary, Theme) now features smooth Material transitions and Android 13+ predictive back.
- Direct Launcher Entry: LauncherActivity now bypasses FirstRun setup directly, seamlessly launching Gboard Pro Settings every time.
- Real-Time Mbps Update Downloads: In-app updater now monitors and displays real-time network speeds in Mbps with transfer statistics and progress tracking.
